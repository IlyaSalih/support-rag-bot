# Как добавить сотрудника

1. Откройте раздел «Сотрудники».
2. Нажмите «Добавить сотрудника».
3. Заполните карточку и нажмите «Сохранить».

## Поля карточки

| Поле | Обязательно | Комментарий |
|---|---|---|
| ФИО | да | полностью, как в паспорте |
| Email | да | на него придёт ссылка для входа |
| Должность | да для реестра | без неё не получится отправить данные в реестр |
| Подразделение | нет | удобно для массового назначения курсов |
| СНИЛС | да для реестра | 11 цифр в формате 123-456-789 01 |

Карточку можно сохранить без должности и СНИЛС, обучение пройти тоже можно. Но **отправить результаты в реестр** без этих полей не получится. Лучше заполнить их сразу.

## Если сотрудников много

Используйте загрузку списком из Excel — так быстрее.
