# Ошибки при загрузке сотрудников из Excel

После загрузки система показывает предпросмотр. Строки с ошибками подсвечены красным, рядом указана причина. Строки без ошибок импортируются, строки с ошибками пропускаются.

| Сообщение | Причина | Что сделать |
|---|---|---|
| «Неподдерживаемый формат файла» | файл не .xlsx | пересохраните файл: «Файл» → «Сохранить как» → «Книга Excel (.xlsx)» |
| «Превышено количество строк» | больше 500 строк | разбейте список на несколько файлов |
| «Не найдены обязательные столбцы» | изменены заголовки шаблона | скачайте шаблон заново и перенесите данные |
| «Некорректный email» | опечатка, пробел, русские буквы | исправьте адрес в ячейке |
| «Некорректный СНИЛС» | не 11 цифр | проверьте номер, допустим формат 12345678901 или 123-456-789 01 |
| «Превышен лимит тарифа» | сотрудников больше, чем позволяет тариф | см. статью «Закончился лимит сотрудников» |

## Совет

Частая скрытая причина — лишние пробелы в начале или конце ячейки. Если ошибка непонятна, проверьте ячейку на пробелы.

## Когда писать в поддержку

Если файл соответствует шаблону, но загрузка не начинается или зависает. Приложите сам файл.
