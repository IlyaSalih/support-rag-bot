# Восстановление пароля администратора

Пароль есть только у администраторов компании. Сотрудники входят по ссылке из письма, им пароль не нужен.

## Как восстановить

1. На странице входа нажмите «Забыли пароль?».
2. Введите email администратора.
3. Откройте письмо и перейдите по ссылке. Ссылка для сброса действует **1 час**.
4. Придумайте новый пароль: не короче 8 символов, хотя бы одна цифра и одна буква.

## Если письмо не пришло

Проверьте папку «Спам». Если email администратора больше не используется (например, сотрудник уволился), восстановить доступ через форму не получится.

## Когда писать в поддержку

Если доступ к почте администратора утерян. Смену администратора поддержка выполняет только по официальному письму от компании на бланке с подписью руководителя. Пароли и данные для входа в чате поддержка не запрашивает и не сообщает.
