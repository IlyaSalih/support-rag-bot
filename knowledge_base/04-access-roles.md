# Роли администратора и сотрудника

| Возможность | Администратор | Сотрудник |
|---|---|---|
| Добавлять и редактировать сотрудников | да | нет |
| Назначать курсы | да | нет |
| Проходить курсы и тесты | да | да |
| Скачивать протоколы и удостоверения | всех сотрудников | только свои |
| Сбрасывать попытки теста | да | нет |
| Отправлять данные в реестр | да | нет |
| Управлять тарифом и оплатой | да | нет |

## Как добавить ещё одного администратора

Раздел «Настройки» → «Администраторы» → «Добавить». Укажите email: новому администратору придёт приглашение. В компании может быть до 5 администраторов.

## Частый вопрос

**Сотрудник видит «Недостаточно прав».** Значит, он пытается открыть раздел администратора. Сотруднику доступны только «Мои курсы» и «Мои документы».
