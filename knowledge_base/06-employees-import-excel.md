# Загрузка сотрудников списком из Excel

1. Раздел «Сотрудники» → «Загрузить из Excel».
2. Нажмите «Скачать шаблон».
3. Заполните шаблон: одна строка — один сотрудник.
4. Загрузите файл и проверьте предпросмотр.
5. Нажмите «Импортировать».

## Требования к файлу

- Формат только **.xlsx**. Файлы .xls, .csv и .ods не принимаются.
- Не больше **500 строк** в одном файле. Если сотрудников больше, разбейте список на несколько файлов.
- Не меняйте названия и порядок столбцов шаблона: ФИО, Email, Должность, Подразделение, СНИЛС.
- Первая строка — заголовки, данные начинаются со второй.

## Что происходит с повторами

Если сотрудник с таким email уже есть, его карточка **обновится** данными из файла, дубликат не создаётся.

Если при загрузке появились ошибки, смотрите статью «Ошибки при загрузке сотрудников».
